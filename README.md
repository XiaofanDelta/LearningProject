# LearningProject - 我的 Java 学习之路

本项目用于记录个人学习 Java 过程中的练习代码与项目，涵盖从基础语法到进阶特性的实践。

## 学习进度

见 [Learning-Progress.md](./docs/Learning-Progress.md).

## 开发环境

 - **语言**: Java
 - **JDK**: 25 (当前开发版本 25.0.2)
 - **IDE**: IntelliJ IDEA

## 目录结构

```text
LearningProject/
└── src/nothing/xiaofan_delta/learning/   # 日常练习代码
```

## 运行方式

对于无构建工具的单个练习文件:
```powershell
javac src/nothing/xiaofan_delta/learning/Main.java
java -cp src nothing.xiaofan_delta.learning.Main
```
